# スプリント練習日誌

短距離の練習日記を書いて X に共有できる、スマホ向けの Web アプリです。

## できること

- **練習日記**：強度（弱・中・強）、ランメニュー（種類・250+50 のような複合距離・つなぎ・r/R のレスト）、ウエイト、その他の練習（ジョグ・ストレッチ・ドリル・補強・プライオ・ケア、いつものセット）、疲労度（練習後 1〜10）、調子を記録。見出しは中身から自動
- **試合結果**：種目・ラウンド・タイム・風速・順位・組・レーン、リレー（走順・区間）。自己記録に自動で反映し、PB・SB更新を判定
- **X に共有**：日記から投稿文を自動で作り、文が入った状態で X の投稿画面を開く（投稿ボタンは X 側で押す）
- **天気の自動取得**：設定した場所の、練習した日付・時刻の天気・気温・風・湿度を [Open-Meteo](https://open-meteo.com/) から取得
- **記録**：PB・SB、リレーのチームベスト、ランメニューごとの練習ベスト（1本・平均）、今週のまとめ
- **距離間のタイム換算**：50m〜400m の 10 距離。手動計時から電気計時への換算付き
- **風の換算**：100m・200m の無風換算と、無風から風ありへの換算（推定値）
- **設定タイム計算**：自己ベストから練習距離の目標タイムを強度別に計算

## データの保存とプライバシー

- 日記はすべて**この端末のブラウザの中だけ**に保存します。外部のサーバーには送りません
- 機種変更や別の端末で使うときは、「記録」タブの「ファイルに書き出す」で保存したファイルを読み込んでください
- iPhone では、ホーム画面に追加して使うと、ブラウザがデータを消しにくくなります（Safari の共有ボタン →「ホーム画面に追加」）
- 外部への通信は Open-Meteo（天気と地名検索）だけです。送るのは約 1km に丸めた位置と日付、または検索した地名だけです

## セキュリティ

- Content Security Policy で、読み込めるスクリプトをこのサイト自身のものに限定し、通信先を Open-Meteo だけに制限
- 外部ライブラリ・トラッキング・広告・外部フォントは使っていない
- 画面に出す文字はすべてエスケープ。バックアップの読み込み時は形式と値の範囲を検査
- API キーなどの秘密情報はリポジトリに含まれていない（Open-Meteo は非商用ならキー不要）

## 計算の出典

- 距離間換算表：[unattachedrunner.com「タイム換算表（スプリント）」](https://unattachedrunner.com/time-correlation-sprint-detail/)
- 100m の風・標高補正：J. R. Mureika, ["Back-of-the-envelope" wind and altitude correction for 100 metre sprint times](https://arxiv.org/abs/physics/0006057)
- 200m の風補正：Mureika (2008) の 200m 補正表に合わせた推定式
- 天気：[Open-Meteo](https://open-meteo.com/)（CC BY 4.0）
